# Github Copilot Docs - Concepts

## Completions

> Code suggestions

1. **Two kinds of code suggestions**:
   - Code completion
     - IDE: VS code, JetBrains, VS, Eclipse, Vim/Neovim, AZ Data Studio, XCode.
     - Programming languages and Frameworks.
       - Works well in Python, JavaScript, TypeScript, Ruby, Go, C# and C++.
       - Generating suggestions for APIs and frameworks.
     - Query generation for databases.
     - Infrastructure as code development.
   - Next edit suggestions (public preview)
2. **Programming languages in Default model**:
   - Code completion
     - C, C#, C++, Clojure, CSS
     - Dart, Dockerfile
     - Elixir, Emacs Lisp
     - Go
     - Haskell, HTML
     - Java, JavaScript, Julia, Jupyter Notebook
     - Kotlin
     - Lua
     - MATLAB
     - Objective-C
     - Perl, PHP
     - PowerShell, Python
     - R, Ruby, Rust
     - Scala, Shell, Swift
     - TeX, TypeScript
     - Vue

> Text completion (PR descriptions)

1. Copilot text completion is currently in public preview and subject to change.

> Code referencing (public repo matching code)

1. **GitHub Copilot provide details** when/on:
   - You accept a code completion suggestion in the editor (matching code is logged).
   - A response in Copilot Chat includes matching code.
   - IDE: JetBrains IDEs, Visual Studio, Visual Studio Code.
   - Others: GitHub website.
