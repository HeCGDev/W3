# Github Copilot Docs - Concepts

## Features

- `[A]` Code completion
- `[B]` Code referencing
- `[C]` Copilot chat
- `[D]` Chat responses (custom instructions)
- `[E]` Chat modes (Ask / Edit / Agent)
- `[F]` Agents:
  - Coding agent
    - Copilot coding agent
    - Custom agent (multi coding agent version)


## Subscriptions

- `[A]` GitHub Copilot Free
- `[B]` GitHub Copilot Pro
- `[C]` GitHub Copilot Pro +
- `[D]` GitHub Copilot Business
- `[E]` GitHub Copilot Enterprise
